# 🧠 MemoryVerse AI

## AI-Powered Digital Identity & Knowledge Repository

MemoryVerse AI is an intelligent knowledge management system that transforms fragmented personal and digital information into a structured, searchable, and intelligent knowledge repository using Artificial Intelligence.

The system helps users organize information, discover meaningful connections, and retrieve knowledge instantly through AI-powered search and recommendations.

---

# 🚀 Features

## 📂 Intelligent Information Organization

- Upload and manage documents and digital resources.
- Automatically process and organize unstructured information.
- Convert scattered data into structured knowledge.

## 🔍 AI-Powered Search & Retrieval

- Semantic search instead of keyword-only search.
- Quickly find relevant information from stored data.
- Context-aware responses using AI.

## 🔗 Knowledge Connection

- Identify relationships between different information sources.
- Build a connected knowledge ecosystem.

## 🤖 AI Assistance

- Generate insights from stored information.
- Provide intelligent recommendations.
- Simplify knowledge discovery.

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/lavanya-62/MemoryVerse-AI.git
cd MemoryVerse-AI
```

---

# Frontend Setup

Navigate to frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Run frontend:

```bash
npm run dev
```

Frontend runs at:

```
http://localhost:5173
```

---

# Backend Setup

Navigate to backend folder:

```bash
cd backend
```

Create virtual environment:

```bash
python -m venv venv
```

Activate virtual environment:

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run backend:

```bash
uvicorn main:app --reload
```

Backend runs at:

```
http://127.0.0.1:8000
```

# 🎯 Problem Statement

Modern users generate huge amounts of digital information, but finding, organizing, and connecting this knowledge is difficult.

MemoryVerse AI solves this problem by creating an intelligent digital memory system that understands, organizes, and retrieves information efficiently.

# 💡 Solution Overview

MemoryVerse AI uses Artificial Intelligence and semantic search technologies to:

- Understand user information.
- Create meaningful knowledge representations.
- Store information intelligently.
- Provide instant and contextual retrieval.
